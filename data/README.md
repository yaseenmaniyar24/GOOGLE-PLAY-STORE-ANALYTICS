# Dataset

This project uses two datasets related to Google Play Store applications
and user reviews.

## Files

### Play Store Data.csv

Contains application-level information such as:

- App name
- Category
- Rating
- Reviews
- Size
- Installs
- Type
- Price
- Content Rating
- Genres
- Last Updated
- Current Version
- Android Version

### User Reviews.csv

Contains user review information used for sentiment analysis.

## Data Processing

The datasets are cleaned and transformed in:

`notebooks/Google_Play_Store_Analytics.ipynb`
